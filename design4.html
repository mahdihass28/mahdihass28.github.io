Design 4: Data Dashboard

A sport / finance analytics and visualisation dashboard

Project Overview

This design will be a data analysis and visualisation dashboard focused on sport statistics or financial data. Users will be able to explore charts and key metrics at a glance.

Planned Features

  • Summary KPI cards (e.g., goals scored, portfolio value)
  • Interactive line and bar charts
  • Date range selector to filter data
  • Data table with sortable columns
  • Responsive two-column dashboard layout

Design Goals

The dashboard will use a dark theme to make data visualisations stand out. Consistent use of colour encoding will let users quickly interpret the data without reading labels.
