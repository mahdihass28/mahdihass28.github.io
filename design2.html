Aperçu du projet

MémoFlip est un jeu de mémoire de type "retournement de cartes" (card matching game) développé en React 19. Le joueur retourne des cartes deux par deux et doit trouver toutes les paires correspondantes. Le jeu mesure le nombre de coups et le temps écoulé, et sauvegarde le meilleur score dans le navigateur.

React 19 Vite CSS Animations localStorage Design centré utilisateur Principes Gestalt

Fonctionnalités

3 niveaux de difficulté — Facile (4×3 · 6 paires), Moyen (4×4 · 8 paires), Difficile (5×4 · 10 paires)
3 thèmes configurables — Espace 🚀, Animaux 🐶, Fruits 🍎
Chronomètre et compteur de coups — affiché en temps réel dans le HUD
Meilleur score persistant — sauvegardé via localStorage par combinaison thème/niveau
Animation de retournement 3D — transition CSS avec transform-style: preserve-3d et backface-visibility: hidden
Accessibilité — attributs ARIA sur chaque carte, support prefers-reduced-motion

Choix de design

L'interface reprend le thème sombre du portfolio (fond #0c0c1d, accent bleu #0d6efd, typographie Inter) pour assurer la cohérence visuelle. Les principes Gestalt sont exploités : la similarité (toutes les cartes dos ont le même visuel), la proximité (la grille forme un bloc unifié), la figure/fond (cartes lumineuses sur fond sombre) et la continuité (animation fluide guidant l'œil).
