Design 2: Memory Game

An interactive card-matching memory game

Project Overview

This design will be a browser-based memory card game. The player flips pairs of cards and must match all pairs in as few moves as possible. The interface will be simple, colourful, and fun for all ages.

Planned Features

  • Grid of face-down cards that flip on click
  • Match detection: matched pairs stay face-up
  • Move counter and timer
  • Win screen with the player's score
  • Restart / shuffle button

Design Goals

The layout will use strong contrast between the card front and back to give clear visual feedback. Animations and colour will create an engaging experience without distracting from gameplay.
